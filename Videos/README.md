# 🎥 Videos

This folder contains demonstration and testing videos documenting the development of the Robotic Dog.

## Current Demonstrations

### Walking Test

**Robotic_Dog_Walking_Test_01.mp4**

First walking experiment of the 12-DOF quadruped prototype.

The video documents the current locomotion development stage and is intended to show the actual hardware behavior rather than a simulation.
